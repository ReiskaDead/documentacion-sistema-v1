# Historial de Cambios (Changelog)

Todos los cambios notables realizados en este proyecto serán documentados en este archivo.
El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/) y este proyecto
adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-09-25

### Añadido
- Módulo de Arquitectura UML con diagramas de Casos de Uso y Secuencia exportados en PNG.
- Subcarpeta de recursos visuales `docs/assets/` para almacenamiento de diagramas.
- Especificación completa de endpoints de API en `docs/api_endpoints.md`.
- Manual de usuario básico en `docs/manual_usuario.md`.
- Documento de arquitectura general y guía de despliegue del servidor en `docs/despliegue.md`.

### Cambiado
- Estructuración modular de carpetas bajo el estándar *Docs-as-Code*.
- Actualización de hipervínculos de navegación en el `README.md` principal.
